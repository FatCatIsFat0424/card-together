# 介面

前端頁面的行為與版面。用戶端架構與連線處理：[架構](architecture.md#前端)。元件慣例：[開發](development.md#ui-慣例)。

## 導覽與版面

- 應用程式填滿一個動態 viewport（手機與窄畫面在固定的頂端列下方，桌機與平板沒有頂端列）。房間與遊戲頁面從不捲動整份文件；較長的帳號頁面、聊天與歷史紀錄在內部捲動。
- 矮的橫向畫面（高度最多 500px、寬度至少 600px）會把頂端列改成 48px 的左側欄，只放圖示：品牌圖示，接著是大廳、好友、訊息、商店、成就，個人選單放在底部。目前所在頁面在側欄邊緣有一條強調色細線；有好友在線時，好友圖示顯示綠點。金幣、通知與音樂移進個人選單（大廳也會在自己的頂端列顯示通知與金幣），選單另有個人頁面、帳號、主題、語言與登出。彈出面板在側欄旁開啟，對局中房號會移進選單。頁面、底部面板與浮動卡片都從側欄右邊開始。
- 桌機與平板（寬度至少 768px 且高度超過 500px）只有固定的左側導覽列，**所有頁面都沒有頂端列**：頁面從視窗頂端開始，與牌桌相同。導覽列在 1024px 以上寬 76px，每個項目是 20px 圖示加 12px 文字：大廳、好友、訊息、商店、成就、戰績（我的個人頁面，含對局紀錄）；目前所在頁面以強調色底板標示，好友有人在線時顯示綠點，訊息顯示未讀數。訊息與成就仍是切換頁面：開啟時再按一次會回到之前的頁面。768–1023px 的導覽列縮成 56px，只留圖示（名稱在 `aria-label` 與提示文字中）。分隔線下方固定放金幣（金幣圖示加數字，12px，保留完成獎勵提示）、通知、背景音樂與頭像選單；彈出面板在導覽列旁、靠底部開啟。頭像選單最上方是頭像、暱稱與金幣，接著是個人頁面、帳號、主題、語言與登出；在帳號頁時頭像按鈕有目前頁面的底板。導覽邏輯在 `components/desktop-nav.ts`，版面在 `DesktopShell`、`DesktopRail`。
- 在房間或對局中時，導覽列最上方多一個強調色的「牌桌」項目，點擊回到進行中的對局（尚未開局時回到等待房間）；在房間、牌桌與回放頁面時它是目前所在頁面。
- 導覽列高度不足時（720px 以下）只留圖示，讓底部的控制項不被擠出畫面。對局中登出仍會先確認。房號在牌桌側欄的「牌局資訊」分頁。牌桌自己的側欄見[桌機牌桌](#桌機)。
- 每個桌機頁面最上方是一列 56px 的頁首（`components/PageHeader.tsx`，捲動時固定）：左側是標題與分頁，右側是摘要與這一頁自己的按鈕。大廳（類別分頁）、商店（分組分頁、系列按鈕與金幣餘額）、好友（分頁與新增好友）、訊息（標題、重新整理、保留期限、關閉）、成就、帳號、戰績與其他玩家的個人頁面（標題與好友或編輯操作）都使用同一列；等待房間的返回、遊戲名稱與動作按鈕也是這一列。其他版面是貼齊頁面頂端、捲動時固定的 40px 頁首（與導覽列同色）。手機橫向省略標題文字（導覽列已標示目前頁面），只留圖示，摘要改用短版（例如「3/23」、「2026/10/28 加入」）；分頁太多時可左右滑動，摘要固定在右側。
- 頁面內容（好友、商店、帳號、成就、個人頁面與訊息的外框）靠左對齊導覽列的右緣，四周留 `--page-inset`，寬度填滿可用空間、最寬 `--page-max`（90rem，超過時靠左而非置中），不留大片空白。桌機版型下好友與成就以卡片格排欄，商店格子加大，帳號分成兩欄；各頁細節見各節。
- 對局中仍可使用導覽：桌機為左側導覽列，手機上則是[遊戲選單](#手機)。帳號、好友、個人檔案與大廳頁面會保留房間成員資格，並可從「牌桌」項目或浮動房間卡片返回。
- 登出是選單的最後一項，以紅色顯示（桌機在頭像選單，窄螢幕與矮的橫向畫面在個人選單）。
- 本人的金幣餘額會搭配[完成獎勵](storage.md#金幣)的提示顯示。
- 房間浮動卡片在手機（寬度 ≤767px 或矮的橫向畫面）縮成可拖曳的單行膠囊，預設在左下（橫向在右下），可吸附到四個角落；膠囊顯示時，根元素帶有 `data-room-card`，頁面以 `--room-card-clearance` 加大底部內距，內容永遠能捲到膠囊上方。桌機仍是完整的卡片，位在右下角，與頁面內容共用同一個外距（大廳裡在社交欄下方，蓋住最少內容）。
- 語音在等待房間使用附文字的「語音」按鈕（頁首較窄時只剩圖示），手機牌桌使用麥克風圖示按鈕（點擊範圍 40px，加入通話時有綠點）；桌機牌桌則是側欄的「語音」分頁，沒有這顆按鈕。它錨定的面板（版面與狀態見[語音](media.md#語音)）保持在 viewport 內，畫面太矮時可捲動；關閉面板或在房間與遊戲之間移動都不會結束通話。全域頁首沒有語音按鈕。
- 音訊設定（主音量、背景音樂、音效、語音聊天）集中在單一面板，行為見[音訊設定](media.md#音訊設定)。
- 房間、牌桌與其彈出面板（選單、設定、旁觀者、bot 管理、玩家卡片）在手機上留 12px 的外距，圖示的圖形對齊同一條邊；彈出面板最高 `calc(100dvh - 24px)`，內容在面板內捲動，從不被裁切。
- 資訊與聊天底部面板，以及導覽列與頂端列的彈出面板，開啟時會把焦點移入，關閉時把焦點移回觸發按鈕。Escape 只關閉最上層。
- 路由錯誤會提供重新載入。部署後若缺少延遲載入的 chunk，每 30 秒最多自動重新載入一次。
- 控制項是無邊框的平面樣式：圖示按鈕只畫 20px 的圖示，但點擊範圍至少 40px；徽章是小圓點或數字；每個畫面只有一個實心主要按鈕（34px 膠囊），其他是半透明的次要膠囊或純文字。分類分頁與篩選使用文字分頁（底線）與 28px 小籤，不使用邊框。所有文字至少 12px，所有佈景主題共用同一組 token。
- 共用按鈕只對顏色與按下的縮放做轉場，不對尺寸或停用時的透明度做轉場。暫時性的請求鎖可以使用 `data-pending-disabled`，保留啟用的外觀但不接受輸入。

## 大廳與好友

- 通知按鈕（桌機在導覽列底部，窄畫面在頂端列）與面板涵蓋收到的好友邀請與已被接受的邀請；私訊不計入它的數量或列表。徽章只計算未讀。面板（桌機 360px）分「今天／較早」兩組，每列有類型圖示（好友邀請藍色、已接受綠色）、句子與時間（一小時內「N 分鐘前」、今天顯示時刻、更早顯示日期）；未讀列淡藍底、名字粗體、右側藍點。點一列會標為已讀並前往（邀請 → 好友頁「收到的邀請」；已接受 → 和對方的私訊）；邀請可以直接在列上接受或拒絕。標題列有「全部標為已讀」，底部有「清除已讀（N）」與「好友邀請 ›」；已接受的列滑過時（觸控螢幕上已讀列一直）顯示 × 刪除單則。邀請在回覆前不會被清除。手機橫向的側欄沒有通知按鈕：大廳頂端列的通知按鈕會切換同一個面板，其他頁面從個人選單開啟。
- 聊天圖示（桌機是導覽列的「訊息」項目）會開啟獨立的 `/messages` 頁面，並顯示私訊未讀總數。兩個徽章在數量為零時隱藏，超過 99 時顯示 `99+`，無障礙名稱中則有精確數字。
- 在 `/messages` 或 `/achievements` 時，對應的導覽按鈕會標示為目前位置，點擊後回到這些區塊之外的上一個頁面（沒有時回到大廳）。訊息視窗以動畫開啟；從它的關閉按鈕或導覽按鈕關閉時，會先播放離場動畫再離開。
- 窄畫面頂端列的切換與目前的導覽連結使用滑動的高亮；彈出面板開關時有動畫。減少動態效果時這些都會立即完成。好友頁面只保留好友與邀請管理。訊息列表與個別聊天會保留房間成員資格。遊戲結果保留返回房間按鈕；導覽、訊息工具列與玩家個人檔案則不另設返回按鈕。仍在房間中時，其他頁面（包括大廳）會在左下角（手機橫向為右下角）顯示精簡的浮動房間卡片。它依即時房間快照顯示遊戲種類、房號、入座玩家、準備人數或對局狀態，以及旁觀人數。點擊它會回到等待房間或進行中／結算的牌桌。它在房間／遊戲頁面、離開房間後與驗證頁面上隱藏；重新連線中會明確標示。大廳使用這張卡片，不另外顯示目前房間的橫幅。手機橫向使用單行的返回連結：狀態燈、遊戲名稱、有人座位／總座位數、房號與 chevron 箭頭，觸控目標為 44px。拖曳這個精簡連結並放開後，它會在 200ms 內滑到頂端列下方最近的角落（減少動態效果時立即完成）；點一下仍會回到房間。在應用程式內切換頁面時，它停留的角落會保留。面板右上角的「關閉」會回到目前的房間或遊戲，沒有加入房間時回到大廳。重新整理、保留期限說明與載入錯誤共用面板的標題列，窄螢幕上會換行。重新整理會同時更新列表與選取的對話；列表與對話相同的錯誤只顯示一次。
- 桌機上，訊息使用分割版面：標題列（標題、重新整理、保留期限、關閉）橫跨上方；左側是可獨立捲動的對話列表（佔 30%，12.5–20rem），最上方是搜尋框（依暱稱、使用者名稱或最後一則訊息篩選），每列 64px：帶外框與上線點的頭像、名稱、時間（今天只顯示時間、昨天顯示「昨天」、更早為月／日）、最後一則訊息（自己傳的加「你：」）與藍色未讀數；有未讀時名稱加粗、時間變藍。右側聊天標頭有頭像與上線點、名稱、裝備中的名牌，第二行是好友目前在做什麼與 @使用者名稱；自己在房間中、對方在大廳時有「邀請進房」，「⋯」可前往個人檔案。訊息之間在換日時插入「今天／昨天／日期」分隔線；同一人當天連續傳送、間隔不超過 5 分鐘的訊息成為一組：對方的組左側有 32px 頭像，名稱與時間在泡泡上方，自己的組只在上方靠右顯示時間；組間 16px、組內 4px、泡泡內距 8/12px、訊息區左右 24px。輸入框提示「傳訊息給 某人…」。手機直式維持分開的列表與對話畫面。矮的橫向畫面（寬度 700px 以上）使用分割版面，但「私人訊息」與重新整理只佔列表欄的上方，「訊息保留 90 天」是列表底部的小字；右欄最上方直接是對話標頭（頭像、名稱、@使用者名稱、狀態與關閉 ×），訊息組不顯示頭像，名稱與時間同樣在泡泡上方。兩種版面都讓標題與輸入框保持在可用的 viewport 內；對話列表與訊息紀錄各自獨立捲動。開啟桌機列表時，各列會由上而下以短暫的錯開時間出現；選取其他對話時保留已掛載的列表，不重播動畫。切換對話時，載入期間仍顯示已知的收件者標題與停用的輸入框。載入文字會等待 180ms，避免快速請求時閃爍；載入的內容在 160ms 內進場，並遵守減少動態效果的偏好。
- 對話列表包含所有目前的好友：先依新到舊列出對話（包括唯讀的前好友），再依目前語系的暱稱順序列出沒有保留紀錄的好友。選取後者會開啟空的對話。目前的好友在頭像右下角（手機直式在名稱旁）顯示綠色上線或灰色離線的圓點，並有已翻譯的狀態提示；前好友與尚未載入上線狀態時不顯示狀態。新訊息會即時重新排序列表；好友列表在好友關係變動、重新連線、重新取得焦點時，以及可見期間每 30 秒重新載入，但對話標示已讀時不會。沒有好友也沒有對話時，列表顯示「No friends yet」。
- 私訊支援既有的表情符號／貼圖庫、較舊紀錄的分頁載入，以及傳送失敗後重試。只有可見的對話會把收到的訊息標示為已讀。前好友的對話是唯讀的；可查看最近 90 天。

大廳的上方是類別分頁（撲克牌、骰子、棋類），依[用戶端遊戲登錄](../client/src/games/registry.ts)的 `gamesInCategory` 決定；沒有遊戲的類別不顯示分頁，目前有撲克牌、骰子與棋類。每款遊戲是一張主題圖卡片，顯示名稱與一行「人數 · 玩法」；選取的卡片有強調色外框。操作區顯示選取遊戲的名稱、一行說明與規則連結、房號輸入（附「加入」）與唯一的實心按鈕「建立房間」。

| 寬度 | 大廳版面 |
| --- | --- |
| 桌機（1024px 以上） | 頁首左側是分類分頁；左側是選取遊戲的大型主視覺（大廳圖案、左側漸層、「人數 · 玩法」、34px 標題、兩行說明、「建立房間」、房號膠囊輸入、規則連結），下方是遊戲卡片格；右側是 300px 的社交欄。兩欄各自捲動，不捲動整份頁面 |
| 平板（768–1023px） | 同一組元件，社交欄移到主視覺與卡片格之間，好友與每日任務並排；整頁一起捲動 |
| 窄畫面（寬度低於 768px） | 問候語與每日控制項、分類分頁、兩欄卡片格；操作區固定在畫面底部，好友在卡片下方 |
| 手機橫向 | 沒有問候語與好友面板；頂端列是分類分頁，右側是每日任務、每日簽到、通知與金幣；卡片排成一列橫向捲動（只有這一列捲動，頂端列與底部操作區固定），高度填滿頂端列與底部操作區之間的空間，圖片取剩餘高度；操作區在底部單行 |

- 每款遊戲都有自己的[大廳圖案](../client/src/assets/lobby-backgrounds/README.md)；卡片使用其縮圖，遊戲開場動畫使用原圖。缺圖時退回純色底板。
- 進入大廳時，卡片與操作區各以 200ms 淡入並稍微上移，卡片間隔約 30ms。好友／獎勵重新整理與選擇遊戲不會重播。系統與應用程式內的減少動態效果偏好會略過這些動畫。
- 規則連結會開啟選取遊戲的說明，不會變更選取或建立房間。
- 桌機與平板的社交欄：線上好友與每日任務兩個面板同寬，都填滿欄寬。線上好友每列顯示頭像、名稱與目前狀態（在大廳、正在玩／等待中加遊戲名稱與人數），好友所在的房間可加入時有「加入」，對局中可旁觀時有「旁觀」；自己在房間內時，在大廳的好友有「邀請」（發出後顯示「已邀請」15 秒）。下方是每日任務的精簡進度條（完成後出現「領取」，替換與完整說明在「查看全部」的對話框）與簽到按鈕，按鈕顯示 +10 金幣或「已簽到」，點擊開啟日曆。分類分頁的選擇存在 `stores/shell-store.ts`，離開大廳再回來時保留。
- Android 瀏覽器會在大廳版面上方看到可關閉的 [Android app](android.md) 下載提示；在已安裝的 app 內與其他平台上隱藏。矮的橫向畫面只顯示它的標題與按鈕。
- 線上好友：房間可加入或旁觀的好友優先，其餘好友垂直捲動。名稱過長會截斷。列表在取得焦點時與可見期間每 30 秒重新整理。手機橫向不顯示這個面板，改由側欄的好友圖示以綠點提示（同樣每 30 秒更新），加入好友的房間請到好友頁面。
- 建立房間或以房號加入需要先離開目前的房間。加入好友的房間會先要求確認，再以一次 commit 切換房間。
- 好友頁面的標題列（桌機是頁首）在所有寬度都是同一組：左側是文字分頁（我的好友、已傳送的邀請、收到的邀請，附即時數量），右側是新增好友的輸入框、「傳送好友邀請」與重新整理圖示按鈕；寬度不足時表單換到分頁下方。桌機版型的好友分「線上 · N／離線 · N」兩組卡片，欄位至少 17.5rem 自動排欄：帶外框的頭像與上線點、名稱旁裝備中的名牌、@使用者名稱、右上角「⋯」（查看個人檔案、移除好友；移除仍需在卡片上再確認一次）；其下是「現在在做什麼」區塊（正在玩 遊戲 · 對局中 · 人數 · 可旁觀、等待中 · 遊戲 · 房主 · 人數、在大廳 · 閒置中），離線時改成一行「N 小時前上線」（沒有紀錄時不顯示）；再下是「一起玩過 N 場 · 最常玩 X」（來自 `/api/friends/stats`，最常玩遵守對方的歷史公開設定，載入前不顯示）；最後是等寬的「訊息」（含未讀數）與依狀態變化的主要按鈕：等待中的房間「加入」、對局中「旁觀」、在大廳且自己在房間「邀請」（發出後顯示「已邀請」15 秒）、離線則只有「訊息」。收到與已傳送的邀請使用卡片，操作是接受與婉拒，或取消。手機橫向不分組，線上的排前面，兩欄的兩行列：36px 頭像與上線點、名稱、一行狀態（離線時加「一起玩過 N 場」），右側是帶未讀數的訊息圖示、主要按鈕與「⋯」。私訊有自己的頁面。操作使用共用按鈕（40px 點擊範圍）。
- 最後上線時間以經過的分鐘、小時或天數顯示（「3 小時前上線」）；不到一分鐘顯示「剛剛上線」，超過 30 天顯示「超過 30 天前上線」，不顯示確切日期。頁面在取得焦點、社交變動時，以及可見期間每 30 秒重新整理。
- 個人頁面（本人與其他玩家）上方是一條標頭：頭像、彩色暱稱、稱號、@使用者名稱、一行摘要（伺服器累計的對局數、勝率、最常玩的遊戲，見下方個人資料列的統計；歷史不公開時不顯示），右側是操作（本人為「編輯個人資料」，其他玩家為好友操作與「管理好友」）；桌機的操作改放在上方的頁首列（標題「戰績」或「玩家個人頁面」）；錯誤與更新訊息顯示在標頭下方。手機橫向與 ≤52rem 的標頭只有 36px 頭像，名稱與摘要各一行。桌機（≥1024px 且高度超過 500px）標頭加寬：72px 頭像、22px 暱稱，摘要變成由分隔線隔開的三個統計格。標頭下方直接接[歷史紀錄](#帳號編輯器)，沒有左右分欄。

## 等待房間

房間頁只有一列頁首、一張座位橢圓桌，以及底部一列操作；沒有固定的旁觀者欄與設定列。

- **頁首**（桌機與平板為 56px，沒有全域頂端列）：返回箭頭（回到大廳，房間成員資格保留，大廳以浮動房間卡片顯示）、遊戲名稱、房號小籤（點擊複製），右側是附文字的按鈕（`ActionButton`），依序是「規則」、「語音」、「聊天」（未讀徽章）、「邀請好友」（人像加紙飛機圖示）、「一起看回放」（只有房主且等待中出現，停用條件不變）與紅色外框的「離開房間」。沒有「⋯」選單，也沒有任何動作收進溢出選單。頁首寬度（container query）不足約 1080px 時，規則、語音、聊天、邀請好友收成只剩圖示（提示與 `aria-label` 保留名稱），「一起看回放」與「離開房間」始終保留文字。邀請清單分「線上 · N／離線 · N」：每列 50px，頭像與上線點、名稱與狀態；在大廳的好友是實心「邀請」，在別的房間的是次要樣式，邀請後顯示綠色「✓ 已邀請」，標題旁顯示「已邀請 N 位」；離線的列變淡、沒有按鈕，只顯示最後上線時間。
- **座位**沿橢圓排列，2–8 個座位共用同一個佈局（`pages/room-oval.ts`）：本人的座位在正下方，其他座位依順序順時針排列，旁觀者則從第一個座位開始。房主在可加開座位的遊戲裡，橢圓上會多一個虛線「＋」讓他新增座位。橢圓桌使用玩家的牌桌背景。
- **座位內容**：頭像（手機 40px，外框留在頭像上）、名稱膠囊（座位框裝飾在膠囊上）與一行狀態：真人為「未準備」或「已準備」（房主永遠是「已準備」），bot 為難度。準備好的座位在頭像角落有綠色勾勾，房主有皇冠，本人頭像有強調色細環，方位或號碼是頭像左上角的小徽章。座位卡底圖是玩家的[座位背景](storage.md)，bot 使用 [bot 荷官圖案](../client/src/assets/room-backgrounds/README.md)；底圖往下變暗，讓名稱保持可讀。
- **桌機座位**（寬度至少 768px 且高度超過 500px）隨視窗放大：頭像、徽章、名稱膠囊與座位卡依 `--seat-scale` 等比縮放（`RoomPage.module.css`），高度超過 500／600／700px 為 1.1／1.2／1.4 倍，1280×800 以上 1.6 倍、1440×900 以上 1.8 倍；名稱與狀態的字級同步升一級（13/12、14/13、15/14px），橢圓桌的最大高度在 1280×800 與 1440×900 提高到 620／700px。縮放以高度為準，8 個座位在 1024×768 與更矮的視窗都不重疊；手機維持原尺寸。
- **空位**是虛線圓圈加「＋」與「空位」。非房主點擊直接入座；房主點擊會開出選單：入座、加入 bot，若是最後一個額外座位還有「移除座位」。bot 座位整張卡片都是管理按鈕（至少 40px），開啟難度選擇與移除。房主在其他真人座位的角落有小的踢出按鈕（觸控範圍 40px）。真人的頭像與名稱連到個人頁。
- **橢圓中央**是設定摘要：人數、局數（德州撲克與梭哈為手數，其他遊戲為玩法標籤）與出牌計時。「房間設定」連結開啟設定面板：遊戲選擇（與大廳相同的類別頁籤，下方以文字標籤列出該類別的遊戲與人數，開啟時停在目前遊戲的類別）、出牌計時、開始時隨機座位，以及所選遊戲自己的選項（牌七、99、瘋狂 8、鬥地主、21 點、拿破崙、五子棋、象棋、暗棋；選項元件由各遊戲的 `roomOptions` 提供）。所有人都能查看；只有等待中、已連線的房主可以變更。
- **底部左側**是「旁觀 n/8」，點擊開啟旁觀者列表（桌機是切換到側欄的「旁觀」分頁，側欄收合時會重新展開；精簡版面是彈出面板）：入座玩家可「進入旁觀區」，房主可拖曳整列（握把在最左邊）把旁觀者放到座位上，或用列尾的「⋯」選單移動、踢出。拖曳座位上的玩家時，這個按鈕同時是旁觀區的放置目標（顯示「拖到這裡改為旁觀」）。
- **底部右側**是房主專用的「bot 補滿」次要按鈕，以及唯一的實心主要按鈕。房主永遠看到「開始遊戲」，人數不足或還有人未準備時停用，沒有準備按鈕（包括房主旁觀、房主轉移與有 bot 的房間）；其他玩家看到「準備」，已準備時是「取消準備」，旁觀者按下準備時會被要求先入座。

| 寬度 | 版面 |
| --- | --- |
| 桌機（寬度至少 1024px 且高度超過 700px） | 橢圓桌置中、最寬 920px、座位依上列放大；右側是 24vw（300–360px）的側欄，分頁為「聊天」與「旁觀」，可收合；頁面外距與其他頁面相同 |
| 精簡（寬度低於 1024px 或高度最多 700px） | 橢圓桌填滿頁首與底部操作之間；聊天從下方滑出，蓋住橢圓桌 |
| 手機橫向 | 同上，頁首與底部操作各縮到 40–44px；706×336 下 8 個座位也不重疊 |

- 桌機的側欄是共用的 `Dock` 元件：文字分頁、收合按鈕，所有分頁保持掛載，所以聊天草稿與捲動位置在切換分頁與收合時保留；聊天分頁在側欄隱藏或停在「旁觀」時累計未讀數，顯示在分頁與頁首的聊天按鈕上。「旁觀」分頁與彈出面板內容相同；底部的「旁觀 n/8」按鈕仍是拖曳與點選移動的放置目標。
- 房間聊天與遊戲內聊天相同，有標題的收合按鈕；同一人連續傳送、間隔不超過 5 分鐘且同一天的訊息合成一組（規則與私訊相同，`messages/message-groups.ts`），名稱、名牌與時間只在組頭顯示一次，每則訊息各自保留聊天框；系統通知與旁觀者專屬訊息不併入組內，組內第 2 則起的螢幕閱讀器文字會補上傳送者名稱；收合期間保留草稿，聊天圖示顯示未讀數。聊天在 200ms 內滑出與滑入，遵守減少動態效果的偏好；被遮住的座位與已關閉的聊天無法接收輸入。
- 進行中的房間操作會鎖住輸入，但不會讓原本可用的控制項變暗，也不會重新建立拖曳目標。原本就無法使用的控制項保留停用外觀。空出的座位立即顯示空位狀態，沒有轉場。
- 房間操作失敗與準備狀態警告，在桌機與手機上都以可關閉、五秒的 toast 顯示，不會把訊息插入房間版面。房間 acknowledgement 錯誤使用選取的語言；未知錯誤使用在地化的通用錯誤訊息，不直接顯示伺服器的原始文字。
- 伺服器更新讓真人玩家坐進空位時，座位卡往上淡入 8px，並在 300ms 內從 96% 經 102% 縮放到 100%。初次載入、準備狀態更新與有人座位之間的交換不會觸發這個動畫；減少動態效果時停用。
- 進入房間時，頁首與設定摘要先往上淡入，座位接著以小幅錯開的彈跳出現，最後是底部操作與桌機聊天。每段動畫 200ms，整個序列在 480ms 內完成。每次進入房間只播放一次，減少動態效果時略過。
- bot 身分顯示「簡單」或「困難」；房主在 bot 管理面板編輯，其他人看到選取的難度。預設值與策略行為記錄在[遊戲](games/common.md#bot)。bot 以目前的座位命名（拿破崙為「Bot 3」，其他遊戲為「Bot S」），並在房主移動它、變更遊戲或還原房間時重新命名。
- 在人數彈性且可加開座位的遊戲（遊戲定義的 `seats.expandable`：99、瘋狂 8、釣魚、21 點、十點半、德州撲克、梭哈、拿破崙、吹牛骰、抽鬼牌與跳棋）中，房主可加開真人座位到八個（拿破崙、釣魚與跳棋為六個）；只能移除最後一個空的額外座位。開始條件：[遊戲](games/common.md#房間流程)。
- 拿破崙依出牌順序把每個座位命名為「Player 1」–「Player 6」（座位徽章顯示號碼），而不是方位名稱與「Seat 5」；等待房間、牌桌、呈現與對局歷史都一致。
- 準備狀態獨立於開始：已連線的入座玩家（房主除外）在人數未滿時就可以準備；房主視為隨時已準備，「開始遊戲」只在遊戲人數足夠且所有其他有人的座位都已準備時啟用。
- 房主可以為任何遊戲啟用自動隨機座位；預設關閉。計時器直接顯示兩個數字欄位，搭配「套用」按鈕。其他人可以查看這些設定。
- 即時開始的對局會顯示可略過的 2.9 秒開場：遊戲的大廳圖案與名稱淡入，所有有人的座位連同頭像與名稱一起出現，最後才顯示牌桌。減少動態效果時改用一秒的靜態顯示。撞擊音效使用經使用者操作解鎖的音效音訊，並跟隨遊戲音效開關。重新連線、重新載入頁面，以及在背景分頁收到的開始都不會重播開場。這段用戶端呈現期間，伺服器的出牌與計時照常進行。點擊或觸碰開場的任何位置，或按 Escape、Enter、空白鍵都會顯示牌桌；底部有一行低調的文字說明這點。

**房主安排座位**

- 整張真人座位卡就是拖曳把手：滑鼠移上去時卡片微微浮起、頂端露出握把，游標變成抓手；拖曳超過 6px 開始。觸控裝置改為長按 0.4 秒才拿起（圓環計時，支援的裝置會輕震一下），短按仍是原本的動作（看個人頁、bot 選單）；手機的旁觀者彈出視窗在拿起時自動收起。Bot 不能被拿起，但可以當落點。
- 拖曳時跟手的是縮小的座位卡；原位置留下虛線與「原位置」，拖回去或放到畫面外就是取消，Escape 也可取消。落點有三種狀態：可放置（虛線外框）、目前指向（藍色實框加光暈，標籤為「交換」「移到這裡」「坐到這裡」）、不可放置（變灰，旁觀者拖到 bot 時顯示「Bot 不可替換」）。座位中央的摘要換成一行即時說明（例如「放開即與 Bot W 交換 · Esc 取消」）。
- 無障礙與鍵盤替代：每張真人座位卡與每列旁觀者都有「⋯」選單，第一項「移到…」列出所有座位與旁觀席並標示「交換」，成功後以 polite 區域通知「已將…移到…」；房主第一次成功換位前，摘要會顯示一行拖曳提示。
- 移到有人的座位時兩人交換。把旁觀者放到真人的座位上，會讓該玩家移到旁觀區。bot 可以和真人交換座位，但從不移到旁觀區。
- 變更會清除真人的準備狀態，並在廣播前保存；儲存失敗會還原原本的安排。

**共同觀看回放**

- 房主底部的「觀看回放」按鈕會開啟依成員分組的已錄製對局選擇器：先列房主自己的歷史紀錄，再列每位公開歷史紀錄的真人成員；不公開的歷史會註明。選擇一場對局就會為整個房間開始播放。
- 房間回放期間，每位成員（以及之後加入的人）都會移到 `/room/:code/replay`：與[對局回放](#帳號編輯器)相同的全螢幕牌桌，加上房間聊天、由誰開始播放、「離開」，房主另外有播放控制與「結束回放」。所有人都從房主以伺服器時間為基準的播放推算目前步驟，所以各牌桌保持同步。
- 結束後所有人回到等待房間；座位與準備狀態延續。聊天會公告開始與結束。

## 牌桌

### 桌機

桌機與平板（寬度至少 768px 且高度超過 500px）的牌桌佔滿左側，右側是可收合的側欄：與[等待房間](#等待房間)相同的 `Dock` 元件，寬度 24vw（300–360px，1920px 以上為 360–420px）。

- 分頁依序是「牌局資訊」、「聊天」、「語音」。牌局資訊放房號、投票終止、提早離開（旁觀者則是離開）與遊戲規則，接著是各遊戲的資訊與回合紀錄，內容與手機選單相同。語音分頁就是語音面板本身（[語音](media.md#語音)），它的 DOM 在彈出面板與分頁之間移動而不重新掛載，所以通話不會中斷。
- 所有分頁保持掛載，聊天草稿與捲動位置在切換分頁與收合時保留。聊天在側欄收合或停在其他分頁時累計未讀數，顯示在分頁標籤上；側欄收合時，牌桌右上角有聊天圖示按鈕（帶未讀徽章），點擊會重新展開，用按鈕收合後焦點移到它。
- 預設狀態：寬度至少 1024px 展開，768–1023px 收合，讓牌桌保持可用；視窗縮到 1024px 以下時自動收合。預設分頁是「牌局資訊」，因為側欄展開時合約與叫牌過程只在這裡（768–1023px 的叫牌面板另外顯示最近叫品）；側欄收合時，合約小籤回到牌桌左上角。
- 旁觀者看到完整的側欄；回放只有在聊天可見時才有聊天分頁，且沒有語音分頁。
- 牌桌的 HUD 只留中央的資訊行；資訊、規則、語音與聊天圖示都改由側欄提供。側欄開啟時牌桌變窄，座位、手牌與操作面板留在牌桌內，不被側欄蓋住。

### 手機

任一方向的手機（寬度低於 768px，或高度最多 500px 且寬度至少 600px）會使用較簡潔的牌桌；桌機與平板版面不變。

- 隱藏應用程式列或側欄。牌桌上方是一列精簡的 HUD：左上角的選單圖示（以徽章標示未讀通知與訊息）、中間選用的資訊行、右上角的語音與聊天圖示（聊天有未讀徽章）。圖示都是 20px 的圖形、40px 的點擊範圍，沒有底板。
- 選單面板列出房號、規則、投票終止與提早離開（旁觀者則是離開），接著是遊戲資訊與回合紀錄、通知、音樂，以及訊息、成就、大廳、好友、商店與個人檔案的連結。
- 座位以計數取代裝飾用的牌背；撿紅點保留吃到的牌。停用的次要手牌操作（外框按鈕）會隱藏；主要操作保留。
- 角落按鈕與螢幕邊緣保持 8px 距離，徽章也留在按鈕內，所以全螢幕的圓角從不會裁到它們。擁擠的直向牌桌會把對面的名牌移開，避免與它們重疊。
- 直向時牌會延伸超出手牌列，由牌桌裁掉底部；牌下方的提示與操作放在這些邊緣上方的半透明列上。
- 桌機與橫向平板的手牌同樣由 `CardHand` 量測手牌列的實際寬度（已扣掉右下角工具面板預留的位置與兩側 24px 扇形邊緣）：牌維持原本的大小，只增加需要的重疊，最少露出 34% 的寬度，仍放不下才縮小牌，所以最大的手牌（鬥地主地主的 20 張）也完整露出、可選取，不會被裁掉或壓在面板下。直向手機不在此列，沿用樣式表的大小。
- 直向手機每場遊戲會顯示 8 秒的旋轉提示；關閉後就永久隱藏（`card-together.rotateHintDismissed`）。

### 棋盤牌桌

棋類使用 `GameShell` 的 `board` 欄位放入 `BoardTable`（`client/src/games/board/`），取代座位環、牌桌中央與手牌列；側欄、選單、規則、投票終止與結算沿用牌桌外框。

| 尺寸 | 版面 |
| --- | --- |
| 桌機 | 對手座位在棋盤上方、狀態（「對手思考中…」）在右上；自己的座位在下方，旁邊是待確認的走法或對手的提和提示，右側是「提和」「認輸」。多人時兩側座位疊在棋盤左右。手數紀錄與「一點即走」設定在側欄「牌局資訊」 |
| 手機橫向（706×336 起） | 棋盤置中、高度為牌桌高度減 24px；左欄是對手座位與最近 4 手的手數條（點擊開啟完整紀錄的抽屜），右欄由上而下是狀態、待確認區（「待確認：…」加固定位置的 44px「確認」與「取消」）或對手的提和提示、提和與認輸、自己的座位。兩欄頂端 40px 留給選單、語音與聊天圖示 |

- 輪到自己（陸戰棋則是還沒布陣）時，棋盤外圍出現 3px 的 `--turn-glow` 光框、自己的座位框亮起，待確認區的位置顯示與牌桌相同的「輪到你了！」膠囊（有待確認的走法、提和提示或布陣工具時讓位給它們）。三者都是靜態樣式，邊框與位置事先保留，所以輪到與否不會移動任何元素。旁觀者與回放從不顯示；螢幕閱讀器由 `GameShell` 的即時區域朗讀，膠囊不重複。多人時其他人的回合由狀態列寫出「輪到{名字}」。
- 選子後顯示合法落點：綠點是空位，橘圈是可吃的子；藍框是最後一手，金色是選取，紅色是將軍。
- 觸控預設「先選再確認」：選定落點後棋盤顯示半透明的虛擬棋子與虛線，按「確認」或再點同一個落點才送出。設定「一點即走」（`card-together.board.oneTap`）可以略過確認；滑鼠、觸控筆與鍵盤一律直接走。
- 對手提和時，提示卡取代待確認區（手機）或出現在自己座位旁（桌機），自己的「提和」暫時停用；不能提和時按鈕停用並說明原因。
- 暗棋：蓋著的棋子都是同樣的棋背，點擊即翻（觸控預設仍先選再確認）；選自己的棋子後顯示可走的格與可吃的子；開啟連吃時，可攻擊的蓋著棋子也標成可吃，選棋後點它即吃暗子（要單純翻開相鄰的棋子，先取消選取），確認列顯示「吃蓋著的」。連吃房規下，吃子後若還能吃，右欄狀態列會出現「結束回合」按鈕；連續 30 步以上沒有翻棋或吃子時狀態列提醒 50 步和局規則。座位旁顯示顏色與剩餘棋子數。未入座旁觀者在棋背上看到淡色的棋子身份。
- 結算沿用共用的結算對話框：標題是「你獲勝／你落敗／和局」（旁觀者顯示獲勝者），下面是結束原因與手數。
- 跳棋：可落點的綠點畫得比其他棋類大；座位依各自的角排在棋盤上方（對角）或左右兩側，旁邊顯示顏色與「到位 n/10」；3 人以上的結算另有可展開的「名次」（名次、顏色、尚差列數或已認輸）。
- 陸戰棋布陣時，`BoardTable` 的 `tools` 欄位（待確認區的位置）放預設陣型、「自動」與「確認布陣」；手機在右欄排成兩欄按鈕。點選己方兩個位置交換棋子，違反限制時以錯誤提示說明原因；對手完成布陣後其空白棋子出現在對方半場。布陣期限顯示在本人座位的倒數。
- 棋盤與棋子的顏色全部來自 `board-theme.ts` 的主題物件（CSS 變數）；商店的棋盤與棋子造型只是另一組主題（見[外觀商店](#外觀商店)）。

### 玩家卡片

在任何尺寸下，點擊入座玩家的頭像或名稱（至少 40px）都會開啟玩家卡片，不需離開牌桌：帶外框的頭像、暱稱、稱號、使用者名稱（bot 則為難度）、這款遊戲的對局數與勝率加上總計（或「match history is private」），以及一列操作：好友狀態或「加好友」按鈕，與個人檔案連結。卡片是單一平面，沒有邊框與分隔的方塊。用來切換視角的旁觀者座位，以及被選為下一位玩家的座位，則維持整個座位的原本動作。

### 共通

- **提早離開**位於投票終止控制項下方。它的確認對話框會說明電腦將代打本局剩下的部分。只有成功保存的代打請求才會讓玩家回到大廳；取消時不改變牌局，錯誤則留在對話框中。房間成員資格會保留，讓玩家可以回來停止代打。每位玩家與旁觀者都會在該座位上方看到持續顯示的**提早離開**標籤，位置和 PASS 相同。其他遊戲狀態保留在座位的詳細資訊中。停止代打會清除離開標記；只開啟代打不會設定它。

- 電腦代打與理牌（花色、數字）是牌桌上的浮動工具（`games/TableTools.tsx`），不在選單或側欄裡；旁觀者、已淘汰的玩家與結算畫面沒有這些工具。
  - 桌機：手牌右下角的一組工具，上面是電腦代打開關，下面是並排的「花色」與「數字」兩個選項，圖示說明大的在左（♠♥♣♦、A › 2）。牌桌寬度不到 1000px 時，整組移到手牌右端上方、本人座位旁，手牌保留全寬。
  - 手機：手牌上方、螢幕左緣有一個 26×64 的把手（高度 360px 以下為 40px），點擊後滑出一排 56px 的直向按鈕（代打、花色、數字）；點空白處、收合鈕、Escape 或 3 秒沒有操作時收回。
  - 代打開啟時開關變成金色「代打中」，理牌選項變淡停用（手牌此時鎖住），手機把手上有金色小點；頂端列右側（語音與聊天圖示左邊）同時有「自動代打中」小橫幅與「停止」按鈕，手牌與面板暫停操作。
- 頂端列可以放遊戲自己的資訊：中央一行 12px 的資訊（`GameUi.hudInfo`；目前只有德州撲克與梭哈的手數、盲注（梭哈為前注與最小下注）與街），對面座位會下移讓出這一行；左側選單圖示旁的合約小籤（`GameUi.hudChip`；橋牌與拿破崙，手機以及桌機側欄收合時）。四人牌桌讓角落圖示浮動，所以對面的座位也會往上移，上方不會留下空的工具列。
  - 兩款都保留資訊欄的墩數進度條：每格固定 4px，代表一墩或一張分數牌，所以進度條長度就是該方的目標；已得的格子填入該方顏色（我方或拿破崙方為主色，對方或防家為警示色），旁邊是「已得／目標」。
  - 橋牌的小籤是三行：合約與莊家座位，其下是「我方」與「對方」的進度條（沒有座位的旁觀者看到南北與東西）；莊家方的目標是合約墩數，防守方是擊垮合約所需的墩數。叫牌時只顯示目前最高叫品。
  - 拿破崙的小籤是三行：合約、拿破崙（「拿」）、小秘書（「秘」），其下是「拿破崙方」與「防家」的進度條。五、六人桌（手機橫向）左右上角的座位會往下移 20px，退進側邊座位之間的空白，讓出小籤的位置。小秘書只在[可見度規則](games/cards.md#拿破崙)允許時顯示（本人、旁觀者，或秘書牌的出牌呈現之後），在那之前改為顯示已公開的秘書牌；雙方進度在秘書牌出現前以「–」與空白的進度條表示。小籤的內容由[純函式](../client/src/games/trick-chip.ts)決定。
- **手機橫向的牌桌**（高度最多 500px、寬度至少 600px）鋪滿整個畫面，工具列圖示、側邊座位、手牌列與操作膠囊都留同樣的 12px 外距，左緣對齊同一條線。底部一列由本人座位（左）與手牌（其餘寬度）組成，沒有固定寬度的名牌欄：
  - 手牌永遠完整露出，不被底邊或按鈕裁掉。牌的大小依螢幕高度決定（寬約為高度的 16.5%，限制在 44–72px），再依手牌列的寬度只增加需要的重疊，每張牌至少露出 34% 的寬度（[計算](../client/src/components/hand-fit.ts)，由 `CardHand` 在量測後套用）。可出的牌浮起，選取的牌浮得更高。
  - 輪到自己與遊戲提示（`GameShell` 的 `prompt`）是手牌上方一行浮動的小膠囊，中央永遠在它上方留出空間，所以不推動任何牌、也不蓋住出牌呈現；叫牌面板開啟時隱藏輪到提示。
  - 明確的手牌操作（出牌／pass、排牌、蓋牌、德州撲克的三個行動）是右下角 34px 高、點擊範圍 40px 的膠囊，手牌列讓出它們的寬度；暫時不可用的次要操作會隱藏。多顆按鈕時排成一欄，德州撲克與 21 點排成一列。
  - 叫牌面板是置中的緊湊卡片，寬度上限 452px：標題與取消在第一列，點數與花色按鈕（至少 40px）在 Pass 與確認膠囊旁。座位名牌已顯示各家最近的叫品，所以面板不再重複列出。
  - 在 706×336 以上（360px 高的手機上、有系統列的 Chrome；全螢幕的 Android app 約為 780×360），中央文字維持在 12px 以上，主要靠重新排列而不是縮放：牌七顯示每一列的兩端與下一個空位，每行兩個花色；騙子酒館、99 與呈現畫格把文字放在牌的旁邊；寬度低於 860px 時，十三支把尾墩放在頭墩與中墩下方；德州撲克把注額放在各自座位朝向中央的一側，公牌下方是底池。
  - 超過四個座位的牌桌把 HUD 浮動到上方兩角，座位改為頭像在左、名稱與數字在右，每個側欄放三個座位；輪到的座位只以頭像光環與倒數弧線表示，秒數留給螢幕閱讀器。706×336 下八個座位不重疊。
  - 在所有 viewport 尺寸下，對話框（包括橋牌重新發牌確認）都疊在玩家名牌上方。矮的橫向畫面中，橋牌與拿破崙的墩使用較大的牌，排成單一水平列，並保留座位標籤與依方向進場的動畫；固定的座位格位讓牌在一墩逐漸出齊時不會移動；拿破崙的首攻花色標籤位於該列下方。
  - 選單面板、結算與投票終止／提早離開的確認框都使用共用的對話框尺寸（`styles/dialog.module.css`）：置中、四邊同樣的外距、標題列 44px、高度最多螢幕高減 24px，只有中間內容捲動，從不被裁切。窄版確認框最寬 400px、單欄；中版（結算、回放挑選）最寬 640px；寬版內容（遊戲規則）維持螢幕寬減 24px。
  - 結算在手機橫向是兩欄：左欄是結果摘要（自己捲動），右欄由上而下是「返回房間」、紀錄按鈕與返回狀態，沒有底部按鈕列；標題靠左，右側標示遊戲名稱。所有遊戲的計分內容都在左欄，包括十三支的各家牌型與德州撲克的排名表。
- 手機直向的牌桌與手牌維持完整寬度，操作列抬高到牌上方、本人座位名牌的旁邊。四人牌桌讓角落控制項浮動，並在對面座位上方留一列按鈕。手牌大小依可用寬度決定，重新發牌提示疊在本人座位名牌上方。矮的直向手機上，側邊座位保留張數，但省略裝飾用的牌背匣，手牌上方的額外空間讓抬高的操作列不被擋住。直向的叫牌面板位於出牌區底部，寬度上限 336px，使用精簡的標題與全高的觸控按鈕。任何操作面板開啟時都會隱藏旋轉提示。超過四個座位的直向牌桌把側邊座位堆成中央兩旁的窄欄，並把工具列浮動到上方兩角。21 點把側邊的手牌移到莊家下方；德州撲克把注額堆在公牌下方，把底牌放在提示旁。直向的手牌放大且重疊更緊，但保持點數角落外露；完整的牌延伸到牌桌底邊以下，由底邊裁掉下半部，選取時會抬起露出更多。
- **德州撲克與梭哈的行動**是三顆膠囊：棄牌、過牌（或跟注與金額）、加注（尚未有人下注時為下注）。點加注會在原處打開一個緊湊的面板：最小、半池、滿池、全下四個快捷鍵、滑桿與金額欄，以及取消與確認；金額一律限制在合法範圍內。滑桿取得焦點、Escape 只關閉面板並把焦點還給加注按鈕，輪到下一個動作時面板自動收起。棄牌的座位只變暗，不加浮動標籤。
- 電腦代打是本局的開關。伺服器使用既有的 bot 策略，只依該座位的私人視角行動；在關閉前，手動的手牌控制項會暫停。重新連線會保留這個選擇；新的對局從代打關閉開始。
- 理牌只改變本機的手牌顯示，保留已選取的牌與遊戲規則。所有遊戲的手牌都由左到右從大排到小，預設順序、依數字與依花色相同：點數大的在左（大老二依它的點數順序，2 最大；牌七的 A 最小，K 最大；騙子酒館依鬼牌、A、K、Q），依花色時花色依 ♠ ♥ ♣ ♦ 分組、組內大的在左（大老二的花色有大小，依 ♠ ♥ ♦ ♣）；拿破崙的大鬼與小鬼排在最左，王牌花色（已定約後）先於其他花色。手牌一律依花色或依數字排列，沒有「未理牌」的狀態：橋牌、拿破崙與牌七預設依花色（與發牌順序相同），其他遊戲預設依數字。選擇會保留到同一款遊戲的下一局；再按一次已選的選項不會取消理牌。拖曳牌或用 Alt+左／右鍵可以從目前的排序開始手動排列，即使還沒輪到自己也可以；此時兩個選項都不高亮，按任一選項就重新排序。手動排列時，打出的牌消失不會打亂剩下的順序，新拿到的牌依上次的排序接在後面。騙子酒館的牌沒有花色，所以只能依數字理牌。21 點分別整理每一手玩家的牌；德州撲克只整理玩家的底牌。

特殊牌的回饋效果在既有的呈現畫格內最多播放一秒，不延長回合截止時間，也不攔截輸入。包括旁觀者在內，所有人看到的都是相同的公開觸發；私人手牌從不影響它。

- 大老二：只有鐵支與同花順。單張、對子、一般順子與葫蘆沒有裝飾效果，包含 2 的出牌也一樣。
- 拿破崙：秘書牌，以及最後三墩之前的大鬼與小鬼。變弱的鬼牌除非是秘書牌，否則沒有效果；一般王牌也沒有。
- 99：只有黑桃 A。呈現保留總數變化、方向符號與被選玩家的名稱，不顯示效果說明。
- 撿紅點：只有成功吃牌且包含紅色 A 時，不論它在哪個位置。其他吃牌與沒有配對的紅色 A 沒有效果。
- 橋牌、瘋狂 8、釣魚與標準牌七：沒有裝飾性的牌效果。釣魚的呈現畫格顯示發問、對象、所問點數與結果，以及湊成的組。瘋狂 8 的呈現畫格直接顯示指定的花色，以及功能牌跳過、罰摸或迴轉的對象。牌七斬龍在出牌畫格之後保留既有的斬龍特效；一般的 7 與 A/K 端點沒有效果。

重新整理後，效果會從目前畫格已經過的時間繼續播放，已過期的效果會被略過。效果不包含文字、標籤或漂浮的牌面符號。已儲存或系統的減少動態效果偏好會以靜態光環取代動畫。牌面、名稱與分數保持可見。

- **座位**以頭像為主，所有牌桌共用 `TableSeat`：頭像（34–40px，外框留在頭像上）、名稱膠囊（12px，座位框裝飾在膠囊上，並提供輪到時的光暈顏色）與一行 12px 粗體的數字（籌碼為金色、張數、點數、叫品）。單一字元的身分標記（莊、D、發，以及拿破崙的「拿」與小秘書的「秘」，完整名稱在提示中）是頭像右下角的小徽章，較長的（小盲、大盲）留在數字行，所以身分堆疊時座位也不會變成三行。
  - 輪到的座位在頭像外有一圈光環，倒數以兩個半圓弧從上方順時針逐漸消失（本人另有紅色的時間庫弧線）；弧線只改變 `transform` 與 `opacity`，在 compositor 上執行，減少動態效果時隱藏。
  - 棄牌、出局與爆牌的座位整體變暗並轉灰階，不加疊在上面的徽章；全下、已擺好、超時代打與提早離開是數字行裡的小膠囊。
  - 玩家有座位背景時，頭像後面是等待房間座位卡的底圖，往下變暗以保持名稱可讀。牌桌座位不顯示名牌稱號。
  - 勝利特效從獲勝者的頭像位置播放。
- 座位與出牌區使用不同的 grid 格，位置依入座人數決定（`seatLayout`、`tablePosition`），本人永遠在下方：2 人面對面，對手在正上方，中央使用左右空出的寬度；3 人為左上與右上（鬥地主等固定 3 人遊戲相同），中央夾在兩者之間，手機橫向的上方座位避開左側選單與右側語音、聊天按鈕；4 人為東南西北十字；5–8 人圍繞牌桌並使用角落位置。德州撲克與 21 點的座位區同樣依人數換格。
- 在橋牌、牌七、騙子酒館、99、撿紅點與拿破崙中，對面的手牌位於上方名牌的右側，讓上方那一列只有一個名牌高，把高度留給中央；寬度低於 600px 時又改回堆疊。它們中央的牌依牌桌決定大小，牌七的各列可以超過一般的中央寬度上限。上方那一列的名牌對齊上緣。側邊格是空的時候（六人），上方角落的座位會往下延伸進去，手牌放在名牌下方，讓上方那一列只有一個名牌高；沒有對面座位時（五人），中央會升到上方兩個角落座位之間。寬度低於 768px 時兩種版面都不適用。拿破崙和牌七一樣取消一般的中央寬度上限。拿破崙的墩牌與出牌框也依牌桌決定大小；完成一墩時，出牌框會變寬並縮小其中的四到六張牌以放得下。拿破崙的墩把牌排在圓角矩形周圍，所以位於兩軸之間的座位會併入上下兩列（六人形成兩列各三張），牌也可以很大。
- 桌機上，側欄的牌局資訊分頁在投票終止按鈕正上方顯示可複製的房號（牌桌頁沒有頂端列）；手機的房號在選單面板最上方。
- 本人手牌的標題包含身分、分數、吃到的牌預覽、狀態、錯誤，以及最右邊的「回合時間 + 時間庫」計時。其他座位只顯示進行中的回合時間。
- 輪到自己時保留文字提示，手牌區周圍沒有發光的外框。減少動態效果的控制項暫時不渲染；已儲存的偏好與動態處理仍然有效。
- 撿紅點會量測牌區，依牌的順序分頁，在高亮吃牌時保持同一頁，並放大牌少的桌面。
- 寬度低於 768px 時，牌七顯示各花色的端點牌與下一個空位，而不是全部十三張。
- 手機與矮的橫向視窗上，投票終止位於牌桌底部。
- 精簡的牌桌 HUD 為規則、資訊、語音與聊天使用一致的圖示按鈕（20px 圖形、40px 點擊範圍）。
- 手機的遊戲聊天在 200ms 內往上滑出開啟、往下滑入關閉，並遵守減少動態效果的偏好。一關閉，它的控制項就會失效。
- 手機與矮的橫向視窗上，牌桌工具列左側有一個一致的純圖示投票終止按鈕；資訊抽屜省略重複的按鈕。所有版面上發起投票終止都需要確認。確認框使用和規則對話框相同的 200ms 開啟動畫與縮小淡出動畫，並遵守減少動態效果。取消不會發起投票；離場動畫期間確認按鈕會停用。
- 結果對話框保持在頂端列下方（矮的橫向畫面中則在側欄旁），聚焦在「回到房間」，並顯示返回處理中的狀態。每墩紀錄或回合紀錄是「回到房間」旁的按鈕，按下後在結果摘要下方展開，不再是摘要裡的摺疊三角。
- 拿破崙：換牌時，拿起的牌會加上星號；換牌、跟牌花色與召喚控制項放在浮層面板中，以維持 44px 的觸控目標。秘書牌選擇器會以虛線標示拿破崙手上或已棄掉的牌，並警告選它們代表沒有小秘書。小秘書的確認依房間與公告存在 local storage，所以重新載入只會顯示一次。座位標籤與通知遵循[拿破崙的可見度規則](games/cards.md#拿破崙)。出牌期間，合約卡包含精簡的秘書牌列與兩列分段的雙方進度。數字顯示已贏得的分數牌，對比各方的獲勝門檻（拿破崙方為叫品，防守方為 17 減叫品）；尚未確定的總數保持未填滿。叫牌表每位玩家一欄，以座位號碼標示（完整名稱在提示與無障礙標籤中），讓六位玩家都放得進資訊欄。叫牌表（橋牌也一樣）把 pass 寫成「P」，提示為「Pass」。墩的紀錄同樣以座位號碼作為欄位標題，玩家名稱放在提示中。
- 回合紀錄（有墩表的遊戲與十三支以外的所有遊戲）依新到舊列出各回合，最新一回合保持展開，直到觀看者自行切換，並把每回合的結果放在標題最後。每一列對齊玩家、牌與結束標記；99 每次出牌各一列並編號。
- 操作需要連線就緒；重新連線期間仍可在本機理牌。

各遊戲的操作方式：[遊戲](games/common.md#卡牌操作)。

## 規則對話框

對話框從中心以 200ms 的縮放動畫開啟（70% 到 105% 再到 100%）。透過按鈕、Escape 或背景關閉時，會在 200ms 內縮小到 70% 並淡出；離場動畫結束前保持掛載。減少動態效果時略過離場動畫。已儲存與系統的減少動態效果偏好都會停用這個動畫。

- 可從大廳的「規則」連結、等待房間的「遊戲規則」按鈕、桌機側欄的牌局資訊分頁或精簡的牌桌工具開啟；玩家與旁觀者都可以使用。
- 等待房間會開啟遊戲規則庫：左側是垂直的遊戲分頁，右側是可獨立捲動的規則，一開始選取房間目前的遊戲。寬螢幕上規則庫總寬度可達 1044px，在 144px 的遊戲分頁旁保留原本 900px 的規則窗格；較小的螢幕則配合 viewport。瀏覽不會改變房間的遊戲；只有目前的遊戲會顯示房間選項。大廳與遊戲內的對話框仍只顯示開啟時對應的那款遊戲。
- 開啟時先顯示簡短摘要（橋牌以外的每款遊戲），接著是啟用中的選項，最後是完整規則（有房規的遊戲，例如牌七斬龍、99 雙副牌、瘋狂 8 功能牌、21 點玩家當莊、五子棋連珠禁手、象棋讓子、暗棋連吃與吃暗子、車衝）。摘要內容與 21 點的對局長度也依照相同的選項；等待房間跟隨房主的變更，對局中使用遊戲狀態，大廳顯示預設值。牌桌的資訊欄沒有另外的規則摘要。
- 閱讀規則不會暫停牌局或計時；結算時會關閉對話框。

- 暱稱、顏色與透明度會立即預覽。暱稱與顏色透過**儲存變更**儲存；頭像外框、外觀裝備、自訂圖片與不透明度會自動儲存。預設頭像（貓、狐狸等）已停用：沒有上傳圖片的人都顯示同一張[預設頭像](../client/src/assets/avatars/README.md)，只能上傳自己的圖片（可移除）；頭像外框套用在預設頭像或上傳的圖片上。bot 座位保留貓頭鷹。
- 切換分頁會保留尚未儲存的個人檔案編輯。
- 分頁使用共用的文字分頁，與「加入日期」一起放在共用頁首（手機橫向改為「2026/10/28 加入」）。寬度 ≤52rem 與手機橫向時，即時預覽與外觀裝備各自收進預設摺疊的區段（40px 高的標題列）；較寬的版面預設展開，預覽固定在左側。所有欄位與按鈕至少 40px 高。

**歷史紀錄與統計**：列表使用[歷史紀錄 API](api.md#http) 的最近 100 筆紀錄，統計使用伺服器累計的[統計 API](api.md#http)：

- 版面分三種。桌機與寬度超過 52rem：欄位為日期、房間、遊戲、結果、玩家、錄製的表格（在自己的容器內捲動，玩家排成一行並自動換行），工具列是搜尋、遊戲、結果與重設。≤52rem 與手機橫向：工具列是一列 40px（搜尋、遊戲、結果與排序下拉選單；篩選或排序偏離預設時才多一個「重設」）；每場對局是一行 36px（遊戲、房號、勝利／落敗／平手徽章、一行摘要、靠右的日期與時間，點擊範圍以偽元素擴到 40px），點擊整列會開啟對局詳情對話框，裡面有結果、時間、所有玩家（可連到個人頁面）與回放按鈕或「沒有錄製」。每次顯示 8 場，「顯示更多」再展開 8 場。手機直式的列把摘要放到第二行。帳號頁的「歷史紀錄」分頁使用同一個元件，因為沒有個人資料列，工具列另有「各遊戲統計」按鈕。
- 搜尋（房號、暱稱、使用者名稱、遊戲、結果）、篩選與排序都在本機進行。「重設」會恢復由新到舊的順序。
- 結果以被查看的帳號為準，包括橋牌的搭檔關係與並列的贏家。
- 勝負只有一份規則（[`matchStanding`](../shared/src/rules/match-standing.ts)），歷史紀錄、統計、成就與每日任務共用：以名次為準，並列取較好的名次，第 1 名（含並列第一）與獲勝的一方算勝場；橋牌依搭檔，拿破崙與小秘書同方。列表仍把並列第一標為「平手」徽章，統計則把它算成勝場並另外列出並列次數。
- **個人資料列的統計**（個人檔案頁，看自己或別人都一樣）併在個人資料列內，整條統計可點，開啟各遊戲統計對話框：統計範圍切換（桌機）、對局數（「全部」範圍旁註記真人場數）、勝率、近 10 場圓點（綠＝勝、紅＝敗、藍＝並列第一；游標移上去顯示遊戲與日期）、最佳連勝（連勝含並列第一）與目前連勝、最常玩的遊戲。視窗寬度 ≥ 78rem 時與身分、操作同一列，較窄的桌機（≥ 64rem）排在身分下方一列；手機與窄螢幕縮成 44px 高的膠囊（場數、勝率、最佳連勝、「統計 ›」），「編輯個人資料」改為 40px 圖示按鈕，範圍切換只放在對話框內。帳號頁的歷史紀錄分頁在列表上方說明列表包含 bot 對局、統計預設只算真人。
- **統計範圍**預設「只算真人」（沒有 bot 座位的對局），可切成「全部」；選擇記在本機（`card-together.history-stats-scope`），統計列與對話框共用。真人範圍沒有任何對局、但有 bot 對局時，統計列與對話框會說明並提供「改看全部」，不顯示零。統計忽略搜尋與篩選。不公開或無法取得的統計不顯示。
- **各遊戲統計對話框**（[伺服器計數器轉換](../client/src/player-stats.ts)、[元件](../client/src/components/MatchStatsDialog.tsx)）：標題列是範圍切換與「累計」（帳號較早的結果已被清除時為「自某日起累計」），特殊紀錄有起算日時再加「特殊紀錄自某日起」（手機橫向不顯示）。左側是總覽與依場數排序的遊戲清單（勝率長條與白色期望值刻度；沒玩過的遊戲收成一行），右側是所選遊戲的指標、名次分布與特殊紀錄；手機橫向時清單變成可橫向捲動的 40px 膠囊，左欄是指標與名次分布，右欄是特殊紀錄。沒有圓餅圖。
  - 排名遊戲：勝率（第 1 名）對照期望值（依每場人數的 1／人數）、平均名次對照期望名次、前二率（三人以上的牌桌）、平均罰分（大老二、牌七、瘋狂 8，附輸的局平均）、平均得分（撿紅點、十三支、抽鬼牌、釣魚、鬥地主）或平均淨籌碼（21 點、十點半、德州撲克、梭哈，相對起始籌碼；依遊戲定義的 `scoreKind`），以及名次分布。遊戲專屬指標：99 最先被淘汰率、十三支倒水率、騙子酒館平均扣扳機、吹牛骰平均損失骰子、抽鬼牌平均每場拿到鬼牌的局數、21 點與十點半爆牌率、德州撲克與梭哈攤牌勝率（爆牌率與攤牌勝率只計有回放的對局）。棋類只有勝率與名次分布，沒有額外指標。
  - 橋牌：勝率（期望 50%）、莊家方合約達成、我主打達成、防守成功、平均超墩。拿破崙：當拿破崙、當小秘書與防守各自的勝率，總勝率對照依角色加權的期望值：每個角色以所有玩家在同一範圍的該角色勝率為基準（全站少於 20 場的角色以 50% 計）。
  - **特殊紀錄**（定義：[`STATS_RECORDS`](../shared/src/stats/definitions.ts)）以卡片列出：圖示、名稱、值（次數、分數、籌碼、線位如 `6♠`、牌型如「葫蘆 K-7」）。達成的稀有紀錄與最佳值以金色顯示，附締造日期；該場仍在已載入的歷史紀錄中且有錄製時，「回放」直接開啟回放。讀取對局紀錄的項目有灰色「紀錄」標籤，還沒有錄製的對局時顯示「還沒有錄製的對局」；有起算日的項目註記「自某日起」。
- 新完成的對局（包括 bot 遊戲）提供錄製，開啟時才載入。錄製的可見度依照被查看玩家的歷史紀錄設定。沒有錄製的對局保留結果，並顯示沒有錄製。
- 遊戲卡片等其他只顯示少量數字的地方，仍以已載入的歷史紀錄即時計算（[`matchStatistics`](../client/src/match-statistics.ts)）。

**對局回放**在該遊戲自己的即時牌桌上全螢幕播放錄製，以未入座旁觀者的身分觀看，所有手牌都可見：

- 完整手牌的檢視遵循該對局的本人／公開歷史紀錄權限。未發出的牌組、騙子酒館的子彈位置、聊天與計時從不錄製。
- 開啟時從頭開始播放。底部的播放控制列取代操作列：播放／暫停、上一步／下一步、開頭／結尾、時間軸、0.5×–4× 速度、步驟計數器與關閉。
- 往前一步會播放該步驟的牌桌呈現與音效；跳轉或往回一步則立即顯示已結算的牌桌。自動播放會等待該步驟新的呈現畫格，至少 900 ms，再除以速度，並在最後一步暫停（[時序](../client/src/replay-playback.ts)）。
- 被查看的玩家一開始位於下方；選擇任何座位即可旋轉視角。回合紀錄與規則仍可使用。聊天、語音、房號、離開控制項與計時都會隱藏，最終結果也沒有回到房間的動作。
- 座位名稱與外觀來自錄製時的帳號，而不是目前的房間。牌桌在自己範圍內的 store 中渲染，所以開著的回放從不改變即時的房間或遊戲。
- 檢視器由步驟、播放狀態與速度控制，所以由房主控制的共同觀看工作階段可以驅動它，同時為其他成員停用控制項，並保留房間聊天。

## 每日獎勵

- 大廳有兩個只有圖示的控制項，與全域導覽分開：每日任務與每日簽到（手機橫向在頂端列右側，窄畫面在歡迎區右側；桌機與平板改放在社交欄的精簡面板，見[大廳](#大廳與好友)）。有可領取的任務或尚未簽到時，圖示上有小圓點。兩者都會開啟對話框。關閉時，離場動畫期間會保留選取的內容與對話框寬度；開始關閉時，獎勵控制項就會失效。 兩個對話框使用共用的[對話框尺寸](development.md#ui-慣例)，四邊外距相等；對話框使用平面列：金幣獎勵、任務說明與進度條、領取（實心）與替換（次要）按鈕；日曆格約 34px 且整個日曆在 706×336 內完整顯示，只有今天可點擊。
- 每個帳號從[任務池](../shared/src/constants/daily-rewards.ts)（玩不同遊戲、獲勝，以及各遊戲的完局任務：除拿破崙外每款遊戲各有一個，21 點、十點半、德州撲克與梭哈共用一個賭桌任務）中取得三個不同的任務，在同一個台灣日曆日內固定，重新整理與重新啟動都不變。任務對話框在所有尺寸都是窄版（約 430px）：標題列有標題與下次重設的倒數，再來是關閉。每個任務是兩行：左邊是金幣獎勵，第一行是任務名稱與 n/目標，第二行是 4px 的進度條；右邊是「更換」圖示按鈕（點擊範圍 40px，有無障礙名稱），任務完成時另有「領取」膠囊（領取後只留已領取標示）。底部一行左邊是「bot 對局也算、並列第一算勝場」的說明，右邊是剩餘的免費更換次數。同一場遊戲可以推進多個任務。
- 每天有一次免費替換，所有任務與工作階段共用。只有已指派且未領取的任務可以替換，包括已完成的任務。替換後的任務不會是原本三個之一；今天先前的活動會計入它的進度。已領取的任務在重設前保持顯示。每個完成的任務都要在對話框中領取。進度在 Asia/Taipei 00:00 重設；未領取的獎勵會失效。bot 遊戲會計入，未完成或被中止的遊戲不計入，並列的贏家不算勝場。橋牌的勝場依搭檔關係計算。
- 大廳第一次載入尚未簽到的台灣日期時，會開啟簽到對話框，並自動領取今天的 +10 金幣；同一天之後的造訪不會。對話框顯示本月的日曆，今天會高亮，已領取的日期會打勾。若自動領取失敗，今天的日期仍可點擊作為備援。
- 簽到對話框把「+10 金幣」與月份標題放在同一行；矮的橫向畫面中月曆格是 28px，只有今天可點的格子以延伸的點擊範圍維持 40px，所以整個對話框放得進 336px 高、四邊外距相同。
- 日期與進度由伺服器提供。開啟對話框、回到頁面、帳號更新與午夜都會重新整理。領取失敗時提供重試；餘額與領取紀錄在持久儲存後，同步到本人所有已連線的工作階段。

## 外觀商店

- 裝飾性的預覽在捲動到可見範圍前不久才掛載，遠離 viewport 時會釋放動態圖案。說明、價格、購買控制項、以文字驅動的預覽，以及可用鍵盤操作的音效試聽都保持可用。預留的預覽空間讓商品格狀版面保持穩定。支援的動態圖案使用和已裝備外觀相同的 compositor 圖層。
- `/shop` 販售[目錄](../shared/src/constants/shop.ts)中永久、純外觀的商品：頭像外框、稱號／名牌、聊天框、貼圖包、牌背、牌面、牌桌背景、籌碼樣式、座位背景、座位框、勝利特效、音效包、棋子、棋盤與骰子。每種類型至少提供十項商品；每個貼圖包包含四張原創貼圖。價格以金幣計算。
- 導覽有三層，所有尺寸同一種樣式：上方是商店分組的文字分頁（個人形象：頭像外框、稱號／名牌、聊天框、貼圖包；牌桌：牌桌背景、座位背景、座位框、勝利特效、音效包；撲克牌：牌背、牌面、籌碼樣式；棋類：棋子、棋盤；骰子：骰子），其下是商品類型的 28px 小籤，附該類型的數量（「全部商品」小籤是該分組的總數），最後是分頁列右側的「系列」按鈕（見下方系列面板）。分組只有在其類型有商品時才顯示分頁，沒有商品時隱藏（[分組表](../client/src/shop-filters.ts)的 `SHOP_GROUPS`；測試會檢查每個商品類型都屬於一個分組）。桌機與手機橫向把金幣餘額放在同一列右側，窄畫面以頂端列的餘額為準。
- URL 參數：`group` 選擇分組，`type` 選擇商品類型（隱含分組），`series` 選擇[目錄](../shared/src/constants/shop.ts)中的主題系列之一或 `other`。沒有 `type` 與 `group` 時，顯示第一個有商品的分組；只帶 `series` 的舊網址會開啟第一個含該系列商品的分組。系列只有 15 個一起設計的主題系列（極光夜旅到獅冠王朝）；單獨設計的商品，例如動物耳朵、金屬與光環頭像外框、獨立稱號與主題貼圖包，不屬於任何系列。商品 ID 必須剛好是「類型前綴＋系列名稱」才算該系列；商品 ID、價格、擁有權與已裝備的圖案都不變。頭像外框類型選取時，小籤列下方多一排小籤：全部、俏皮造型、金屬系列、光環系列（舊版的 `ears`、`metal` 與 `special`，`?series=ears` 等舊網址照舊可用；選取後類型固定為頭像外框，選取其他類型時忽略），這些舊分類不在系列面板中。系列篩選套用在目前分組，小籤數量也反映該系列；選取主題系列或「其他」時，商品上方出現系列橫幅（縮圖、名稱、動態系列標記、說明、「已擁有 x / y」與「清除系列」），選取舊版邊框分類時小籤列右側顯示商品總數；空的結果會說明如何選擇其他類型或系列。切換類型或分組時保留選取的系列。重新載入與瀏覽器的上一頁／下一頁會保留篩選；不認得的篩選，包括已刪除的系列（例如 `?series=cats`）或空的分組，會回到第一個分組。
- **系列面板**：按鈕未選取時顯示「系列 全部 ▾」，選取後變成縮圖＋系列名稱＋✕（✕ 清除系列）。點擊後桌機在按鈕下方浮出面板（5 欄），手機橫向與窄版從右側滑入（3 欄、可捲動）。面板列出「全部系列」、「其他」（`?series=other`，所有不屬於系列的商品）、10 個主題系列與 5 個有動畫的動態系列；每格是系列縮圖（靜態畫面）、名稱與**目前分頁**中的件數（[`shopSeriesCounts`](../client/src/shop-filters.ts)），件數為 0 的格子變暗但仍可選。選取系列時網址帶上目前分組，避免分頁跳到其他分組。
- 商品格子（手機約 5–6 欄；桌機版型 1024px 以上為至少 10.5rem 的卡片，1280px 約六欄）每張卡片只顯示預覽、名稱與價格（金色）、「裝備」按鈕或「✓ 已裝備」（藍色外框），不顯示商品說明；整張卡片是開啟詳細對話框的按鈕，已擁有但未裝備的卡片多一個「裝備」按鈕，一點就換上；預覽縮到卡片大小（`FitArt`；縮放以耳朵、鹿角、觸手與徽記等外凸裝飾的實際範圍計算，整個外框都在卡片的預覽區內，動態裝飾不計入；所有卡片在同一批次中量測，網頁字型載入後重新量測），裝飾性、不可操作，聲音試聽在詳細對話框中。稱號卡片把名牌放在較小的頭像下方，讓名牌文字在手機橫向也清楚可讀；座位背景卡片中的頭像連同外框裝飾一起縮進背景內。每種類型的預覽都只在接近畫面（上下 400px 內）時才掛載，離開後卸載，畫面外的預覽也不繪製，因此不在畫面上的動畫不佔用主執行緒（[`ShopProductArt`](../client/src/components/ShopProductArt.tsx)、[`art-fit`](../client/src/components/art-fit.ts)）。預覽實際的圖案、套在玩家頭像上的外框、稱號，或貼圖包中的所有貼圖。星穹遠征、千燈神域、鋼鐵戰線、霓虹失控與獅冠王朝各自加入原創的動態向量場景、徽記，以及四張表情豐富的貼圖。場景裝飾集中在邊緣附近，保留出牌區；動畫遵守減少動態效果的偏好。遊戲與等待房間的牌桌、牌背，以及頭像與稱號徽記，會把這些場景畫成建置時產生的圖片圖層，由瀏覽器移動而不重新繪製（`client/src/cosmetics/art-layers/`）；分割工具無法重現的新動態圖案會讓建置失敗。商店與帳號預覽顯示原始檔案。任一個減少動態效果設定開啟時，顯示原始的靜態畫面，隱藏或在畫面外的圖層會暫停。選擇外框以外的類型時，小籤下方會以一行小字說明該類商品會在哪裡顯示（頁面標題只供螢幕閱讀器使用）。滑過或聚焦金幣餘額時，會說明每完成一場遊戲可得 10 金幣。購買與金幣規則：[儲存](storage.md#外觀物品欄)。
- 點擊卡片（裝備按鈕除外）會開啟同一個詳細對話框（手機橫向為預覽在左、文字在右），只顯示預覽、名稱、「類型 · 系列」、價格與購買後餘額，不顯示商品說明或「永久持有」之類的固定說明。可裝備的商品另有「裝備後會取代」：目前的外觀縮圖 → 新商品縮圖；若目前顯示的是自己上傳的圖片，會註明圖片會保留、可在個人頁切回。按鈕順序為「取消」（靠左）、「只購買」、「購買並裝備」（主要）；金幣不足時兩個購買按鈕停用並顯示「還差 N 枚金幣」。購買並裝備與裝備後，頁面底部出現提示，附「換回原本的」按鈕（把該欄位改回先前的商品或預設，不退款）。貼圖包只有「購買」；成功後對話框改顯示四張貼圖與「前往訊息」「完成」。已裝備的商品與已擁有的貼圖包只能關閉。取消不會改變金幣，購買或裝備進行中無法關閉對話框。
- 裝飾（貓、兔子、青蛙、熊、狗、鹿角、觸手）會隨頭像縮放。原本的單色外圈與商店外框有相同的外側範圍。
- 帳號頁面可以選擇已擁有的外框或原始頭像。已裝備的外框會顯示在大廳、個人檔案、好友、聊天與房間中，且不會遮住頭像。
- 已擁有的外觀商品可以從商店或帳號編輯器裝備。帳號頁的「外觀裝備」把欄位圖卡分成個人形象（大家都看得到：頭像邊框、稱號與名牌、聊天框）、牌桌（牌桌背景、座位背景、座位框、勝利特效、音效包）、撲克牌（只有你看得到：牌背、牌面、籌碼樣式）、棋類（只有你看得到：棋子、棋盤）與骰子（只有你看得到）；每張圖卡顯示目前的縮圖、欄位名稱與裝備名稱，使用上傳圖片時標示「自訂 · 80%」（牌桌背景與牌背帶不透明度）。點圖卡後，桌機在圖卡旁浮出選擇面板，手機是滿寬對話框，列出已擁有的商品縮圖與最後一格「前往商店（還有 N 款）」；選擇後立即儲存並關閉。牌桌背景、座位背景與牌背的選擇面板另有「自訂圖片」：上傳（上傳後自動套用）、更換、移除，已有上傳圖片時它取代「預設」，移除後回到預設；牌桌背景與牌背的不透明度滑桿在面板底部，對上傳圖片與商店樣式都有效。移除官方圖片樣式會恢復仍保留的上傳圖片或主題。名牌把固定且已在地化的外觀稱號，搭配自己的標記與配色，與取得的成就分開。已裝備的名牌會顯示在玩家身分與房間聊天中的暱稱旁，但不會出現在精簡的旁觀者列表中。商店預覽使用和已裝備名牌相同的稱號樣式。牌桌背景與牌背是私人的；座位背景會顯示在等待房間中。帳號選擇器為下列類型提供「預設」。既有的上傳圖片、主題與表情符號仍然免費。
- 較新的裝備類型在未裝備或無法辨識時，會退回內建設計：

  | 類型 | 誰看得到 | 位置 |
  | --- | --- | --- |
  | 牌面 | 本人 | 每一張正面朝上的牌，包括騙子酒館的鬼牌與拿破崙的大鬼，其灰階版本就是小鬼（經典牌組使用內建的鬼牌圖案）；四色牌組依需求載入重新上色的牌面，載入前先顯示經典牌面 |
  | 音效包 | 本人 | 輪到、加入、出牌、pass、淘汰、開始、牌七斬擊、翻桌、擲骰、開骰、落子、吃子、翻棋與將軍音效；音效聲道與主音量都會套用，包括點擊播放的商店試聽 |
  | 籌碼樣式 | 本人 | 每一個籌碼圖示（德州撲克、梭哈、21 點、十點半、回合紀錄、座位） |
  | 棋子 | 本人 | 所有棋類共用的棋子元件（象棋與暗棋的圓棋、鬥獸棋、黑白棋與五子棋的棋子、跳棋彈珠、陸戰棋的翻開棋子）：面色、雙方顏色、邊框（雙圈、珠點、刻痕）、光澤與字體。暗棋與陸戰棋蓋著的棋子、跳棋彈珠的六個角落顏色、落點與上一步等提示標記固定不變 |
  | 棋盤 | 本人 | 所有棋盤形狀（格子、交叉點、星形、鐵路、河道）的底色、線條、文字與邊緣；跳棋的角落顏色固定。動態系列在棋盤與棋子之間加一層緩慢移動的光（只改 `transform`／`opacity`），永遠在棋子文字與落點提示下方；減少動態效果時不顯示 |
  | 骰子 | 本人 | 吹牛骰的骰面、點色、骰盅與看不到的骰子；動態系列的骰盅有脈動光暈 |
  | 座位框 | 所有人 | 遊戲中座位的名稱膠囊與等待房間座位的名稱膠囊；框的顏色提供輪到時的光環，取代主題的輪到光暈 |
  | 勝利特效 | 所有人，包括旁觀者 | 結算出現時，從每個獲勝的真人座位的頭像位置播放約 3 秒，每次結算一次；從不遮住或擋住結果對話框。減少動態效果時顯示靜態光暈 |
  | 聊天框 | 所有人 | 寄件者在房間聊天與私訊中的訊息；系統訊息從不加框 |

- 棋子、棋盤與骰子依 15 個原生系列的主題參數（材質、顏色、邊框、字體；[`series-tokens.ts`](../client/src/cosmetics/series-tokens.ts)）程式化產生，經由共用的 `BoardView` 與棋子元件套用，新棋類不需要另外接線。產生時會自動調整顏色以維持對比度，測試逐款檢查：棋子文字與雙方顏色（象棋紅黑、鬥獸棋紅藍）可讀且明顯可分，黑白棋與五子棋的黑白棋子對比足夠，棋盤線條與文字清楚，骰子點數可讀且「一」與其他點色不同。
- 購買的貼圖包會出現在房間聊天與私訊的貼圖選擇器中；不需要裝備步驟。收到貼圖不需要擁有它。
- 表情符號／貼圖選擇器（房間聊天與私訊共用）從表情按鈕往上展開，貼在訊息區左下角，最大 440×420px，較寬的對話仍看得到旁邊與上方的訊息；窄的房間聊天欄與手機上則填滿訊息區。上方只有一列 48px：「表情／貼圖」切換、可左右滑動的分類（我的、站方，貼圖模式再加上已擁有貼圖包的縮圖）、搜尋圖示與商店圖示（前往貼圖包）；點搜尋時同一列變成搜尋框（← 回到分類、× 清除），結果列出所有分類的符合項目。格子 44px（商店貼圖佔 2×2），開啟時選第一個有內容的分類。窄的房間聊天欄會縮小列上的間距。
