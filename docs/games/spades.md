# 黑桃王（Spades）

房間、觀戰、計時、中止投票與回放沿用[共通規則](common.md)。

## 發牌與叫牌

- 固定四人：南北（N/S）對東西（E/W），對家是搭檔。
- 標準 52 張牌，每人 13 張；A 最大、2 最小，黑桃永遠是王牌。
- 第一手隨機選莊家，之後每手順時針輪莊。從莊家左手邊起，順時針每人叫一次 0–13 墩。
- 0 為 Nil：個人承諾一墩不吃。沒有盲叫 Nil，兩位搭檔可同時叫 Nil。

## 出牌

莊家左手邊首攻，之後順時針出牌。有首引花色必須跟花，缺門可打任何牌，包括黑桃。墩中有黑桃時由最大黑桃獲勝，否則由首引花色最大牌獲勝；贏家首攻下一墩。

有人打出黑桃才算解禁；解禁前不能首引黑桃，但手上全是黑桃時例外。第一墩沒有額外禁牌或罰分限制。13 墩打完才結算。

## 每手計分

兩位搭檔的**非 Nil** 叫墩相加為隊伍合約，只有非 Nil 玩家的吃墩能履約。

| 項目 | 分數與袋數 |
| --- | --- |
| 非 Nil 合約成功 | 每叫一墩 +10 分，每超墩 +1 分並加一袋 |
| 非 Nil 合約失敗 | 每叫一墩 −10 分 |
| 個人 Nil 成功（零墩） | +100 分 |
| 個人 Nil 失敗（至少一墩） | −100 分；每個吃墩另加一袋、+1 分 |
| 累計每滿 10 袋 | −100 分，餘數跨手保留 |

失敗 Nil 的吃墩**不補搭檔合約**，即使非 Nil 合約失敗，這些吃墩仍算袋並各得 1 分。袋數扣分與 Nil、合約得分相加。

例如 N 叫 Nil 吃 2 墩，S 叫 4 吃 3 墩：合約失敗 −40，Nil 失敗 −100，Nil 吃墩 +2 並加兩袋，本手為 −138 分（尚未計入累計十袋扣分）。不能拿 N 的兩墩補 S 的合約。

搭檔同叫 Nil 時，非 Nil 合約為零且自動成功，所有失敗 Nil 的吃墩都算袋。譬如兩人各吃一墩，本手 Nil 共 −200，加兩袋及 2 分，合計 −198 分（尚未計入十袋扣分）。

## 勝負

每手完成後，任一隊累積達 **500 分**就比較總分：若兩隊同時達標，高分隊獲勝；完全同分則再發一手。獲勝隊伍的兩位搭檔一起獲勝。沒有負分淘汰門檻，也沒有固定手數上限。

## 操作與自動代打

- 叫牌時選擇數字或 Nil，再按確認；出牌時只可選亮起的合法牌。手牌預設由大到小，可使用共用理牌工具。
- 側欄顯示各家叫墩／吃墩、隊伍累積分數與袋數，逐手明細列出合約、Nil、超墩袋數與十袋扣分。結算對話框保留整場逐手明細。
- 逾時與自動代打使用同一個 bot，不會跳過叫牌或任意棄權。bot 只讀自己的過濾後視角，推測別人的牌一律靠抽樣，不偷看。

## Bot

- **搜尋**（[程式碼](../../server/src/bots/spades-search.ts)）：bot 回合與真人逾時在 worker pool 中做[決定化搜尋](../architecture.md#決定化搜尋)，每步預算 1.2 秒。每個樣本把未見的牌發給其他三家：張數與已顯示的缺門（含未解禁就首攻黑桃代表只剩黑桃）是硬限制，各家叫牌依手牌估計值加權。每個候選出牌（相對未見牌等價的張數只算一次）或候選叫品（啟發式叫品前後各兩墩，牌型接近時加上 Nil）都用快速策略打完整手，以本隊實際的本手結果比較：合約、Nil、超墩與十袋扣分，留下的袋數每袋另扣 5 分，打完會結束比賽時再加減勝負獎勵。叫牌時尚未叫的座位依啟發式和各自抽到的手牌叫。差距在雜訊內時沿用啟發式的偏好。
- **啟發式**（[程式碼](../../server/src/bots/spades-strategy.ts)、[推論](../../server/src/bots/spades-knowledge.ts)）：沒有 worker、搜尋失敗或樣本不足時使用，也提供搜尋的候選順序。
  - 叫牌：大牌依花色長度打折，黑桃算大牌與長度，短門配多餘的黑桃算王吃；搭檔已叫 Nil、四家合計超過 14 墩、袋數接近 10 時調整。手上大牌風險低時叫 Nil，搭檔叫得多或落後 150 分以上時較積極，搭檔已叫 Nil 時不叫。
  - 出牌：追蹤缺門與未見牌，估計後面的對手能否壓過。合約未達或還能讓對手倒約時爭墩：搭檔的牌大概守得住就墊小牌，二家在搭檔殿後時只用大概守得住的牌，三家用最便宜而守得住的牌；首攻先清王牌（握有最大黑桃且張數不少於其他人合計）、兌現對手不太可能王吃的大牌、讓缺門的搭檔王吃，否則從長門出小牌。合約已達且無法讓對手倒約時避免吃袋。保護搭檔的 Nil；對手的 Nil 還活著時讓它吃墩，並往它還有的花色出小牌。等價的牌隨機選擇，避免固定花色順序。
