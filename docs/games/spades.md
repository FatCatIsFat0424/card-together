# 黑桃王（Spades）

房間、觀戰、計時、中止投票與回放沿用[共通規則](common.md)。

## 發牌與叫牌

- 固定四人：南北（N/S）對東西（E/W），對家是搭檔。
- 標準 52 張牌，每人 13 張；A 最大、2 最小，黑桃永遠是王牌。
- 第一手隨機選莊家，之後每手順時針輪莊。從莊家左手邊起，順時針每人叫一次 0–13 墩。
- 0 為 Nil：個人承諾一墩不吃。沒有盲叫 Nil，兩位搭檔可同時叫 Nil。

## 出牌

莊家左手邊首攻，之後順時針出牌。有首引花色必須跟花，缺門可打任何牌，包括黑桃。墩中有黑桃時由最大黑桃獲勝，否則由首引花色最大牌獲勝；贏家首攻下一墩。

有人打出黑桃才算解禁；解禁前不能首引黑桃，但手上全是黑桃時例外。第一墩沒有額外禁牌或罰分限制。13 墩打完才結算。

## 每手計分

兩位搭檔的**非 Nil** 叫墩相加為隊伍合約，只有非 Nil 玩家的吃墩能履約。

| 項目 | 分數與袋數 |
| --- | --- |
| 非 Nil 合約成功 | 每叫一墩 +10 分，每超墩 +1 分並加一袋 |
| 非 Nil 合約失敗 | 每叫一墩 −10 分 |
| 個人 Nil 成功（零墩） | +100 分 |
| 個人 Nil 失敗（至少一墩） | −100 分；每個吃墩另加一袋、+1 分 |
| 累計每滿 10 袋 | −100 分，餘數跨手保留 |

失敗 Nil 的吃墩**不補搭檔合約**，即使非 Nil 合約失敗，這些吃墩仍算袋並各得 1 分。袋數扣分與 Nil、合約得分相加。

例如 N 叫 Nil 吃 2 墩，S 叫 4 吃 3 墩：合約失敗 −40，Nil 失敗 −100，Nil 吃墩 +2 並加兩袋，本手為 −138 分（尚未計入累計十袋扣分）。不能拿 N 的兩墩補 S 的合約。

搭檔同叫 Nil 時，非 Nil 合約為零且自動成功，所有失敗 Nil 的吃墩都算袋。譬如兩人各吃一墩，本手 Nil 共 −200，加兩袋及 2 分，合計 −198 分（尚未計入十袋扣分）。

## 勝負

每手完成後，任一隊累積達 **500 分**就比較總分：若兩隊同時達標，高分隊獲勝；完全同分則再發一手。沒有負分淘汰門檻，也沒有固定手數上限。

## 操作與自動代打

- 叫牌時選擇數字或 Nil，再按確認；出牌時只可選亮起的合法牌。手牌預設由大到小，可使用共用理牌工具。
- 側欄顯示各家叫墩／吃墩、隊伍累積分數與袋數，逐手明細列出合約、Nil、超墩袋數與十袋扣分。結算對話框保留整場逐手明細。
- 簡單 bot 依自己的牌力叫牌、隨機出合法牌；困難 bot 另判斷保守 Nil、保護搭檔 Nil、搭檔已安全贏墩時保留控制權，必要時接手，並以經濟的贏牌爭墩；相對未見牌等價的張數會隨機選擇，避免固定花色順序。兩者只讀自己的手牌與公開狀態。
- 逾時採困難 bot 的合法策略，不會跳過叫牌或任意棄權。
