# 紅心

四人各自計分的吃墩遊戲；目標是避開罰分，遊玩時間約 20–40 分鐘。房間、觀戰、回放與中止投票沿用[共通規則](common.md)。

## 發牌與交換

- 使用標準 52 張牌，北、東、南、西各拿 13 張。點數由 A 到 2，沒有王牌。
- 第一副向左傳三張（北 → 東 → 南 → 西），第二副向右、第三副傳對家，第四副不換牌，之後循環。
- 每人秘密選三張不同的手牌並確認，四人全部提交後才同時交換；提交後不能修改。其他人只知道誰已提交。
- 交換共用一個截止時間，時長為房間每回合時間、至少 30 秒；從發牌呈現結束後開始。未提交者由系統從自己的可見視角選三張合法牌。

## 出牌

1. 持梅花 2 者以該牌首攻第一墩，順時針各出一張。
2. 有首攻花色必須跟牌；缺門才能墊其他花色。首攻花色最大者贏墩，並首攻下一墩。
3. 紅心被打出後才解禁；解禁前不能首攻紅心，除非整手只剩紅心。黑桃 Q 不會使紅心解禁。
4. 第一墩缺梅花時，只要還有非罰分牌，就不能墊紅心或黑桃 Q；如果全手都只有罰分牌，才能墊一張。

## 計分與結束

| 牌 | 罰分 |
| --- | --- |
| 每張紅心 | 1 |
| 黑桃 Q | 13 |
| 其他牌 | 0 |

贏墩者收下該墩的罰分。包辦全部 26 分稱為「射月」：自己加 0 分，其他三人各加 26 分。

13 墩全部打完才結算。先呈現本副加分與累計，再自動進入下一副，不必按確認。任一玩家累計達 100 分時，在該副結束對局；累計最低者獲勝，最低分相同可並列。

## 操作與 bot

- 交換時點三張手牌，再按確認交換；出牌時只能點可出的牌。手機先點選，再點一次確認出牌。手牌預設由大到小排列，可用共用牌桌工具切換理牌。
- 側欄顯示本副罰分、累計、紅心是否解禁、各副分數與公開出牌紀錄。結算表保留每副加分與射月標記。
- 簡單 bot 隨機交換及出合法牌；困難 bot 優先傳走危險高牌，在同風險換牌及接近的好出牌之間增加變化；跟牌時盡量壓在目前贏牌之下，缺門時優先墊罰分牌，末家面對無罰分墩時可安全卸高牌。兩者只使用自己的手牌和公開狀態。
- 出牌逾時與交換逾時均使用困難策略；策略失敗後由平台回退到第一個合法動作。交換內容與初始發牌不進入公開紀錄。
- 統計記錄射月、零罰分副數及單局最低罰分；每日任務可要求完成一局紅心。
