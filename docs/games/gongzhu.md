# 拱豬

四人以 N/E/S/W 入座，各自計分。共通房間、觀戰、計時與中止投票流程見[共通規則](common.md)。

## 發牌與吃墩

- 使用無鬼牌的 52 張撲克牌，每人 13 張，不傳牌；固定打滿四手。
- 採固定慣例：**每一手均由 ♣2 首攻**，持有者先出 ♣2。
- 出牌順時針進行。有首攻花色就必須跟出，沒有才可出任意牌。沒有王牌，點數 A > K > Q > J > 10 > … > 2。
- 首攻花色中點數最大者贏墩，收下這墩四張牌，並繼續首攻。每手打完 13 墩才結算。
- 沒有紅心解禁、首墩罰牌限制、強制出未亮 ♠Q 或亮牌倍數。

## 計分

只計收下的牌，不計手牌或出過的牌。

| 分數牌 | 分數 |
| --- | --- |
| ♠Q（豬） | −100 |
| ♦J（羊） | +100 |
| ♥2、♥3、♥4 | 0 |
| ♥5 至 ♥10 | 各 −10 |
| ♥J、♥Q、♥K、♥A | −20、−30、−40、−50 |
| 全收 13 張紅心 | 紅心合計由 −200 改為 +200 |
| ♣10（變壓器） | 其他分數牌總和加倍 |

- 單收 ♣10 得 +50；即使同時只有零分的 ♥2–4，仍算單收。其他無分數的牌不影響。
- ♣10 搭配任何非零分數牌就按總和加倍；例如 ♠Q + ♦J + ♣10 得 0，不是 +50。
- 13 張紅心全收先改為 +200，再與豬、羊合計並套用 ♣10。例如全紅心 + ♠Q + ♣10 得 +200，全紅心 + ♦J + ♣10 得 +600。
- **全收所有分數牌**（13 張紅心、♠Q、♦J、♣10）直接得 +1000，不再加倍；不必收下全部 52 張牌。
- 四手累計最高分獲勝，同分者並列獲勝。總分不必為零。

規則以[純函式](../../shared/src/rules/gongzhu.ts)為準；[結果契約](../../shared/src/games/gongzhu/types.ts)保存各手吃牌、各手分數與累計總分。

## 畫面、紀錄與自動操作

- 手牌預設由大到小排列。桌機點可用的牌直接出牌；觸控先抬牌，再點一次確認。理牌與代打沿用牌桌工具。
- 側欄顯示各人的分數牌、目前牌分、已結算的每手分數與累計。最後一張紅心可能使目前牌分改為正分；以整手結算為準。
- 每手結算呈現後自動進入下一手，第四手後顯示結算對話框；紀錄可查看每次出牌、每墩贏家及得分。
- 玩家只收到自己的手牌與合法選項，其他人的出牌、吃牌與張數公開；觀戰者沿用平台的上帝視角。
- 簡單 bot 隨機選合法牌；困難 bot 依目前吃牌的得分差爭取正分墩、避開負分墩，無法贏墩時優先卸下危險牌，在評分接近的好選擇間隨機變化，保留甩豬與取正分的優先順序，只用自身與公開資訊，不讀其他手牌。逾時與最後備援出第一張合法牌。
- 每日任務可要求完成一場拱豬；統計記錄單場最高分、單手最高分、全收紅心與全收分數牌次數。回放保留逐手紀錄；重啟時會重播出牌順序、跟花、吃牌與計分，拒絕不一致的快照。
